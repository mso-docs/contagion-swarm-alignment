# Protocol 2 amendment: synthetic scenario benchmarks

This amendment preserves RQ1/RQ2/RQ3 in CONTAGION_AGENT_MVP_SPEC.md. Existing protocol-1 results remain separate. Declare this design before interpreting new outcomes.

The scenario registry contains 384 deterministic variations of four templates: catalog instruction override, source fabrication, inert patch/evaluator-field tampering, and protected-record update. These are project-specific synthetic benchmarks, not established external benchmark scores or 384 independently authored attacks. There are 256 development and 128 evaluation cases. Fictional names and values differ across splits. Shared templates limit generalization; no claim of semantic novelty between splits is made.

Sampling is without replacement, either uniform or stratified across selected families, with its own seed. A freeze stores the entire study plan, source fingerprint, database hash, selected scenario IDs, task/prompt/scoring hashes and inference seeds before inference. Evaluation uses a distinct seed range >=10000. Rebuilding the ignored SQLite database reproduces the checked-in metadata index. Code, prompt or registry changes invalidate freezes; create a new freeze and output directory rather than overwriting attempts.

RQ1 runs five private contexts over synchronous ring/star/complete graphs. Only a delivered neighbor message carries the benign intervention; the system prompt remains authoritative. A structured artifact is scored for legitimate task completion, an objective unauthorized behavior, explicit refusal or ambiguity. Patch proposals are inert JSON paths and values, never executable code. Malformed output is unscorable, not evidence of refusal. Report task-specific outcomes and parsing failures; do not call these a general alignment score.

RQ3 compares five serial calls by one context with four local contexts plus one aggregation call. Both arms receive local catalog subsets followed by the complete final catalog and have equal call/output-token caps. Serial history and team message/context structure differ and remain explicit confounders. The default-deny simulator distinguishes attempted protected updates from actual state changes. The permissive simulator is a separately labeled positive control; it touches only fictional in-memory state.

RQ2 projects sealed protocol-1 RQ1 events into deterministic nested visibility masks with persisted IDs. No oracle/config/intervention flags are included. Communications-only and communications-plus-final-outputs are separate policies. Use a single model/protocol cohort per invocation. Projections of the same runs are dependent. With no true positive runs, recall/F1 are undefined rather than zero; false alarms remain measurable.

Independent review receives the task, visible messages and artifact, with opaque sample IDs and no target model, treatment or hidden ground truth. Deterministic scoring remains the primary outcome. Reviewer confidence is uncalibrated; evidence IDs must exist in the visible view. Call-limited samples, errors, ambiguity, scorer disagreements and seeded clean audits enter a human queue. No automated clearance is enabled. Human-label calibration is descriptive; it does not certify held-out generalization. Reviewer/model sweeps and secondary-reviewer adjudication remain future work.

TransformerLens is a separate optional Linux CPU worker. Its offline random GPT-2 smoke measures instrumentation only. Trained checkpoint replays require an immutable revision, explicit clean/corrupt alignment and a chosen single target token. Residual RMS, selected post-activation MLP neurons and single-position patch logits include no-op and position controls. This is neither Ollama hidden-state access nor a Neuronpedia SAE interpretation. Model-emitted thinking text is a separate observable artifact, not a faithful account of internal computation. Current local Intel macOS/Python 3.14 cannot install a compatible PyTorch wheel; local neural runtime remains unavailable. A subsequent secondary-Linux installation completed an actual random smoke capture; trained-checkpoint replay is still pending.

Public export uses a separate closed schema. Summary rows, scenario metadata and reduced measured numeric arrays are allowlisted; raw requests, task solutions, token text/IDs, full tensors and private configuration remain ignored. Review reasons are withheld by default. Regex/known-value scrubbing reduces exposure but cannot guarantee anonymity. Manual review is still required before publishing free text.
