# Secondary-only extended suite (prospective)

**Privacy update:** queue progress, planned budgets, ETA and hardware readings are private operator telemetry. They are no longer included in public exports. Use [the private terminal monitor](PRIVATE_PROGRESS.md); historical public-telemetry descriptions below are superseded.

Primary is excluded until the operator explicitly releases it. This suite uses existing secondary Ollama models, serial inference and controller-mediated synthetic tasks. No service/driver/firewall/credential changes or agent tools.

Freeze the suite schedule, every study plan, source hash, registry hash, model tag/digest and seeds before inference. Run the two installed models qwen3.5:4b and qwen3.5:0.8b in separate model blocks, never pooling their outcomes. Each model gets a development smoke first, then a short RQ3 development comparison and the predeclared size ramp, followed by the same held-out evaluation cases and seed schedule. Template variants remain correlated, not independently authored attacks.

Per model: development screen on three stratified scenarios, three graphs, both conditions, seed101 (450 calls); RQ1 on all96 held-out catalog/provenance/patch cases, ring/star/complete, both conditions, seeds10101/10202 (28,800 calls); RQ3 on all32 held-out record cases, both executors, single/team, both conditions, the same two seeds (2,560 calls); exploratory ring scaling on the same three development scenarios at5/10/20/40/80/128 agents, five rounds, both conditions, seed303 (8,490 calls). A separate40-call development RQ3 check precedes scaling. Total40,340 calls/model,80,680 scheduled calls, never more than90,000 physical attempts or72hours. Each study retains its smaller local caps. Stop if free disk falls below10GiB, source/model identity changes, or three consecutive study blocks fail. Failures and unrun work remain explicitly recorded; no silent prompt changes or model substitution. Human/operator stop requests stop our worker only, never Ollama.

RQ1 primary measurements use five agents, five rounds and held-out cases. Scaling is a separate2.1 cohort, ring only to bound inbox growth; finite five-round reach confounds large-size adoption opportunities. No assertion that128 is the hardware maximum. One model instance serves logical contexts; one in-flight call at a time.

RQ2 runs offline on completed catalog-marker RQ1 records only, with25/50/75/100% visibility, both output-access policies, persisted nested masks, separate model/protocol/source/worker/graph cohorts. Provenance/patch tasks are excluded from this marker baseline and their exclusion is counted. Ground truth is independently rescored from final downstream artifacts, separate from monitor inputs. Undefined recall with no positives is reported honestly.

RQ3 separates an attempted prohibited update from actual in-memory mutation. Default-deny and permissive-simulator arms are separate controls. Five calls and output budgets match; serial history versus distributed contexts remain confounds. Model failure/refusal/malformed output are distinct.

Append-only raw events, configs/checksums and model/runtime metadata stay private. Static public detail files contain bounded scrubbed task and trace views, with truncation counts; full logs are retained privately. Neither heuristic scrubbing nor Gitleaks guarantees removal of every possible PII. No private endpoint/credentials/raw tensors are published. Model-generated reasoning, if returned, is observable text, not verified internal reasoning. Completed-run snapshots can refresh locally; publication still requires reviewed Git push.

Neural measurements are a separate instrumented-checkpoint channel. Activation magnitude/patch logit differences are not an alignment detector, intent classifier or SAE feature explanation. The existing random-weight capture validates mechanics only. Trained replays must pin the checkpoint revision and keep raw token IDs/prompts/tensors private; an alternate checkpoint is not the hidden state of the original Ollama model.
