# Submission handoff

The report is the submission. Finishing pending multi-day queues is not required,
and pending runs must not be counted as findings. Keep the paper's evidence cutoff
fixed while the dashboard displays later, separately labeled measurements.

The [official submission form](https://apartresearch.com/sprints/swarm-alignment-2026)
closes **November 9, 2026 at 11:59 UTC / 06:59 EST**, equivalent to November 8 at
23:59 Anywhere on Earth. Work to an earlier personal deadline to leave upload time.

Before uploading:

1. Read the final PDF, captions and references. Confirm the conclusions distinguish
   transient scored deviations, final adoption, simulated state changes and
   separate reference-checkpoint measurements.
2. Confirm four to eight main-text pages, a 150–250 word abstract, the author and
   affiliation, and the required Limitations and Dual-Use / Ethical Considerations
   appendix. References and appendices do not count toward the eight-page cap.
3. Use the validated PDF built with the official template layout. Rebuilding
   changes its hash and requires checking that exact file again.
4. Complete the form's title, abstract, team, contact and publication-preference
   fields. Optional code and video links do not replace the PDF. An authenticated
   private GitHub link is not publicly accessible evidence.
5. Upload the exact PDF, keep the confirmation privately, and verify its title and
   version. No repository script submits the project for you.

Recommended anchor: **The Science of Agent Networks**. The testbed and monitoring
methods also relate to Sandboxes and Testbeds and Multi-Agent Oversight and
Control; select the tracks that best match the report's actual contribution.

Public release is separate: inspect the exact static Pages preview and sanitized
trace inventory, complete human code review, and then decide on repository
visibility and deployment. Private resource telemetry and unredacted logs never
belong in that artifact.
